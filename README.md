# Filing structure proposal

A proposal for organizing a commercial real estate document library by owning entity
rather than by topic.

**The issue.** Nobody can tell from an address whether a property is commercial or
residential. That classification lives in people's heads, not on the page. Someone on
their first day cannot file a single document without stopping to ask.

**The solution.** So make ownership the organizing question, and let everything below it
be forgiving. The entity is printed right on the paperwork. The insurance names the
insured, the note names the borrower, the invoice names the bill-to.

Four roots, six folders in every entity, seven in every building.
